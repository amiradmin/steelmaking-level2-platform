# Steelmaking Level 2 — Project Roadmap

> Planning baseline. Nothing in this roadmap is considered completed unless explicitly updated later.

## Milestones

| Milestone | Target window | Goal | Status |
|---|---|---|---|
| M1 — Engineering Baseline | 2026-09-29 → 2026-10-18 | Architecture, environments, requirements, tag/interface baselines | Planned |
| M2 — Level 1 / PLC Integration | 2026-10-19 → 2026-11-15 | EAF/LF/CCM connectivity, tag maps, quality and failover | Planned |
| M3 — Functional Level 2 | 2026-11-16 → 2026-12-13 | Heat tracking, historian, alarms, KPIs, operator workflows | Planned |
| M4 — Production Hardening | 2026-12-14 → 2027-01-10 | Security, observability, backup/restore, performance, HA readiness | Planned |
| M5 — FAT / SAT / Commissioning | 2027-01-11 → 2027-02-07 | Acceptance, plant validation, training, go-live readiness | Planned |

## Workstreams / Epics

1. Platform architecture and engineering baseline
2. Level 1 / PLC / OPC UA integration
3. Historian and industrial data management
4. Heat management and process orchestration
5. Event and alarm management
6. Operator UI, dashboards and reporting
7. Authentication, authorization and cybersecurity
8. MES / Level 3 integration
9. DevOps, deployment and observability
10. Quality assurance, FAT/SAT and commissioning

## Status policy

- **Planned**: defined but not started.
- **Ready**: sufficiently specified to begin.
- **In Progress**: active implementation.
- **Blocked**: waiting on dependency or decision.
- **Review**: implementation finished, awaiting validation.
- **Done**: only when explicitly approved and acceptance criteria are met.

All items start as **Planned/Open**.
